1자동 편성 규칙

1. 통합 그룹
같은 그룹 학생을 인원이 가장 적은 반에 통째로 넣어요.
2. 분리 그룹
같은 그룹 학생을 서로 다른 반에 넣어요.
3. 동명이인
이름이 같은 학생도 서로 다른 반에 넣어요.
4. 나머지 학생
성적 높은 순으로, 인원이 적은 반부터 넣어요. 인원이 같으면 같은 성별이 적은 반을 골라요.
5. 인원 맞추기
반끼리 인원 차이가 1명 이하가 될 때까지 옮겨요.
6. 성적 맞추기
같은 성별끼리 바꿔서 반 평균 차이를 자동 편성에서 고른 기준 안으로 줄여요.
